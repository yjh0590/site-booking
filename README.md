# 🐣 콕콕 예약알림

> 예약이 열리면 콕콕이가 바로 **휴대폰 알림**으로 콕! 찔러드려요.

전시·공연·체험 예약 페이지 주소를 등록해 두면, 콕콕이가 주기적으로 대신 확인하다가
**예약이 열리는 순간** 폰으로 알림을 보내 줘요. 앱 설치 없이 웹 브라우저 알림으로 동작하고,
내 컴퓨터에서 직접 실행하니 개인정보가 다른 곳으로 가지 않아요.

- 📱 안드로이드·아이폰 모두 알림 지원
- 🔍 "접수예정 글자가 사라지면", "예약하기 버튼이 생기면"처럼 조건을 골라서 등록
- 👨‍👩‍👧 초대 코드로 가족·친구와 함께 사용
- 💸 무료, 회원가입 없음

---

## 1. 준비물

| 준비물 | 설명 |
|---|---|
| 컴퓨터 | Windows / Mac / Linux. **켜져 있는 동안만** 확인해요 |
| [Python 3.10 이상](https://www.python.org/downloads/) | Windows는 설치할 때 **"Add python.exe to PATH"** 체크 |
| 휴대폰 | 안드로이드(크롬·삼성 인터넷) 또는 아이폰(iOS 16.4 이상) |

## 2. 실행하기

### Windows
1. 압축을 풀고 **`start.bat`** 을 더블클릭하세요.
2. 처음 한 번은 필요한 것들을 자동으로 설치해요. (1~2분)
3. 검은 창에 이렇게 나오면 성공이에요.
   ```
   🐣 콕콕 예약알림 실행 중 → http://localhost:8000
      초대 코드: abc123   확인 주기: 5분
   📱 폰에서 이 주소를 여세요 (가족·친구에게 공유해도 돼요):
      https://어쩌구-저쩌구.trycloudflare.com/?code=abc123
   ```
4. 이 창을 **닫으면 콕콕이도 멈춰요.** 켜 둔 채로 두세요.

### Mac / Linux
```bash
pip3 install -r requirements.txt
brew install cloudflared        # 폰 연결용 (Linux는 아래 링크 참고)
python3 server.py
```
cloudflared 설치: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/

## 3. 폰에서 쓰기

창에 나온 **📱 주소**를 폰으로 보내서 열어요. (카톡 나에게 보내기 추천)

**안드로이드**
1. 주소 열기 → **알림 켜기** → 알림 허용
2. **테스트 알림 받아보기**로 알림이 오는지 확인

**아이폰** (Safari에서)
1. 주소 열기 → 아래쪽 **공유 버튼 → 홈 화면에 추가**
2. 홈 화면에 생긴 🐣 콕콕 아이콘으로 열기
3. **알림 켜기** → 알림 허용 → 테스트 알림 확인

> 💡 컴퓨터에서 `start.bat`을 다시 켜면 주소가 바뀌어요. 이미 등록한 폰은 **알림은 계속 오고**,
> 목록을 보거나 새로 등록할 때만 새 주소로 들어가면 돼요.

## 4. 사이트 등록 요령

예약 페이지를 열어서 **지금 보이는 상태 글자**를 찾는 게 핵심이에요.

| 지금 페이지에 보이는 것 | 고를 조건 | 글자 |
|---|---|---|
| `접수예정`, `준비중`, `오픈예정`, `매진` | **이 글자가 사라지면** ⭐ 추천 | 그 글자 그대로 |
| 열리면 생길 버튼을 알 때 | **이 글자가 생기면** | `예약하기`, `신청하기` 등 |
| 잘 모르겠을 때 | **뭐든 바뀌면** | (비움) — 공지만 바뀌어도 알림이 올 수 있어요 |

**예시** — 국립광주과학관 특별전 페이지에 `접수예정`이 보인다면 → **이 글자가 사라지면** + `접수예정`

## 5. 설정 바꾸기 (선택)

`start.bat` 맨 위에 `set 이름=값` 줄을 넣거나, 터미널에서 환경변수로 지정해요.

| 이름 | 기본값 | 설명 |
|---|---|---|
| `CHECK_MINUTES` | `5` | 몇 분마다 확인할지. 너무 짧게 하면 사이트에 부담이 가요 |
| `INVITE_CODE` | 자동 생성 | 초대 코드를 직접 정하기. 자동 생성 코드는 `invite.txt`에 저장돼요 |
| `PORT` | `8000` | 다른 프로그램과 포트가 겹칠 때 |
| `TUNNEL` | (켜짐) | `0`이면 폰용 주소를 만들지 않음 |
| `VAPID_SUB` | `mailto:noreply@example.com` | 알림 서비스에 알릴 연락처. 본인 이메일 권장 |

예: `set CHECK_MINUTES=3`

## 6. 24시간 돌리고 싶다면

- **가장 쉬움**: 컴퓨터 절전 모드 끄기 (설정 → 시스템 → 전원 → 절전 "안 함")
- **컴퓨터를 끄고 싶다면**: Oracle Cloud 무료 VM 같은 클라우드 서버에서 같은 방법으로 실행하세요.
  고정 주소가 필요하면 cloudflared의 이름 있는 터널(named tunnel)을 쓰면 돼요.

## 7. 자주 묻는 질문

**Q. 알림이 안 와요.**
테스트 알림부터 확인 → 폰 설정에서 브라우저 알림 허용 여부, 방해금지 모드 확인 →
아이폰은 홈 화면 아이콘으로 열었는지 확인.

**Q. ⚠️ 접속 실패가 떠요.**
사이트가 잠깐 느리거나 점검 중이면 그럴 수 있어요. 계속되면 브라우저로 주소가 열리는지 확인하세요.
클라우드 서버에서 실행 중이라면, 해외 접속을 막는 사이트일 수 있으니 국내 리전 서버를 쓰세요.

**Q. 등록했더니 "페이지 내용이 거의 안 보여요"라고 나와요.**
화면을 자바스크립트로 나중에 그리는 사이트(일부 예매 사이트)라 감지가 어려워요.
그 기관의 **공지사항·게시판 페이지**를 대신 등록해 보세요.

**Q. 처음부터 다시 하고 싶어요.**
콕콕이를 끄고 `booking.db`를 지우면 등록 정보가 초기화돼요.
`invite.txt`를 지우면 초대 코드가 새로 만들어져요.

## 8. 보안 안내

- 초대 코드를 아는 사람만 새 기기를 등록할 수 있어요. **코드와 주소는 아는 사람끼리만** 공유하세요.
- 콕콕이는 등록된 공개 웹페이지만 읽고, 공유기 관리 페이지 같은 내부망 주소는 접속하지 않아요.
- `vapid.pem`(알림 서명 키), `invite.txt`, `booking.db`는 **다른 사람에게 주지 마세요.**
  공유할 때는 이 파일들을 빼고 주세요.

## 9. 파일 구성

```
start.bat          Windows 실행 (더블클릭)
server.py          콕콕이 본체 (웹 서버 + 주기적 확인 + 알림 발송)
watch.py           페이지 비교 로직 (단독 실행도 가능: python watch.py)
web/               화면 (index.html), 알림 처리(sw.js), 아이콘
requirements.txt   필요한 Python 패키지
test_server.py     자가 점검: python test_server.py
```
